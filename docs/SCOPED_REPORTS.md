# Scoped WaveLink reports

Under HR > Reports, choose a report type and filters, then Download PDF, Excel or CSV. The new PDF uses the same server-scoped rows and stale-report protection as Excel. It never expands the report to other employees or includes the original attachments. Expense amounts remain grouped by currency in the PDF; approval is not payment.

In Fleet > Water & Fuel, use PDF report or Download Excel. All vessels returns the comparison across authorised vessels, with recorded-day counts and no-data states. Selecting a vessel returns product totals and saved daily stock balances for the same UTC period. Unsaved demo exercises are excluded and demo PDFs are clearly marked.

No migration or new write permissions. Existing individual exports remain unchanged.
