## One page to assign ordinary work

Use **Tasks → New task**, or the existing Home creation action. Select **General work**,
**Maintenance activity** or **Certificate check** in the same form. Enter the title and instructions,
choose people, optionally set a due date, then **Create task**. No separate type chooser, four-page
wizard, generic reason or routine review checkbox. The Create button is the explicit assignment.

Priority starts Normal; due time is optional and explicitly UTC. No date or assignee is invented.
The responsible department does not automatically assign all its members. Creation still requires
administrator or authorised current department-head access. Saving creates one open Task with
empty checklist results, not completed work. Module permissions remain enforced by the service.

## Find people and keep selected records

**Find people** searches name, login and account ID. Searching does not uncheck people outside
its results; the selected count is separate from visible rows. A retained saved-draft person or
department missing from the current eligible directory stays visible, rather than being silently
removed. The service can refuse it until the selection or access is corrected deliberately.

**Linked record** expands for an optional exact asset, maintenance order or certificate reference.
Search and refresh retain the selected identity/version even outside the results. A changed source
is not silently updated: **Use its current saved version** is a deliberate action. A failed record
lookup blocks creation until retried or No linked record is deliberately chosen. Linking grants no
source access and copies no readings, files, approvals or dates.

**Checklist** expands the existing scratch/template builder. No checklist is selected automatically.
Its specific template-copy sharing consent and compatibility rules remain; a saved checklist is a
fixed Task-owned copy. Task submission/final review remains distinct from recording its results.

## No generic reason for updating your own result

Task work notes already save without a generic reason. Now updating **your own Task-checklist
result** in an allowed working state is reason-free too. Wavelink still records the genuine actor,
time, version and before/after result. It does not invent an explanation.

**Issue** and **Not applicable** still need a meaningful step note. **Resetting a saved result to
Not recorded**, replacing another person's result or correcting unknown authorship still needs a
short explanation. Required readings, limits, assignment, working-state and review rules remain.
An identical status/readings/note is the existing no-op, not a new version. Existing actual reasons
in resumed local drafts are retained as optional wording unless the correction needs one.

## Retain drafts and retry without duplicate work

**Keep draft & close**, resumption and the existing draft recovery remain. Old ordinary four-step
drafts open in the new form with their choices intact. The saved destination opens only after the
hub save and local-draft cleanup finish. A lost response or confirmed save followed by local cleanup
failure keeps the same request for retry; it does not create another Task or result. Conflicts retain
wording without overwriting newer saved work. A changed account/view prevents new submission;
preserve and reopen the form in the original account rather than clearing storage.

Navigation and search do not submit or acknowledge anything. No new persistent store, autosave
system, automatic reminder or automatic completion was added. Real-device storage acceptance
remains outstanding.

## Other workflows stay separate

**Inventory verification instead** is collapsed below the normal form. Its explicit button keeps
this Task draft before opening the existing fixed-scope verification workflow. Fault report →
corrective Task retains its reviewed source-sharing flow; it is not silently converted to ordinary
Task creation. Review, return, cancellation, reopening, reassignment and postponement are unchanged.

Completing a Task does not finish a maintenance order, renew a certificate, verify stock or release
equipment. Simple handovers/files, QR visitors and signing PDFs, maintenance/certificates, Original
Files, project activity, website icons and **support@mywavelink.com** remain intact.
The hosted ordinary Task form displays UI38; other feature badges retain their own version.
Native GUI layout and installed Windows binaries have not been redesigned or rebuilt.
