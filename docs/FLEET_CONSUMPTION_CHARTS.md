# Fleet consumption charts

The Consumption view shows freshwater (m³) and diesel (L) as separate calendar-day charts for the selected vessel and range. Totals sum only recorded days. Blank days are missing, while a dot on the zero line marks an explicit zero. The existing product selector and expandable daily balances below the charts preserve exact values and the balance inputs. The change is presentation-only: database, calculations, permissions and practice-only behavior are unchanged.
