# Wavelink 1.34.45

## Checklist authoring

Users with checklist editing permission and OpenAI assistance enabled can start a checklist directly from the builders page, describe it in their own words and review the suggestions. The editor offers one action to apply the selected suggestions and save the draft to the template library. Bulk selection selects new values and preserves existing fields and manual checklist items.

The editor saves work in progress to the signed-in user's account. Reopening restores manual fields, the OpenAI brief, suggestions and their selection. The save indicator reports when progress has reached the server. A separate confirmation identifies a draft saved to the template library. Server revisions protect against a second editor overwriting newer work. Selective project transfers exclude private working copies.

## Other editors

HR, IT, handover, builder and inventory import screens retain pending input or warn on departure according to each editor's save model. The shared dialog guards include inventory stock actions, equipment certification and access proposals. HR recovery retains the form in the current tab. Users can select a document inside the assistance panel and review OpenAI suggestions before committing changes.

Handover notes and pending OpenAI selections are private to the author and the selected shift or handover. A personal working copy can be reopened after restarting the application. Selective project transfers exclude pending personal notes.

## Employee document reminders

The HR alerts use the document's configured advance-notice period and show the current milestone at 90, 60, 30, 14 and 7 days when applicable, on the expiry date and at weekly intervals afterward. The existing email settings and recipient opt-in govern delivery.
