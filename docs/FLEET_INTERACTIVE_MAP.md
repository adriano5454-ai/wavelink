# Fleet basemap

The map of manually reported positions uses a locally bundled Natural Earth 5.1.2 land layer. The browser does not contact a tile service to display it. The world land geometry is 1:50m, generalized for a small browser payload; when zoomed into the Rio coast the app layers in a clipped 1:10m coastline. The Natural Earth source files and their SHA-256 digests are recorded in deploy/fleet_map_land.json. Source: https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson. Public-domain terms: https://www.naturalearthdata.com/about/terms-of-use/.

Positions are the last manually reported values, not AIS or an electronic navigational chart. Demo positions off Rio de Janeiro, Cabo Frio and Macae are fictional and are created only in isolated public Demo sessions. Private workspace records are unchanged. Natural Earth is the in-app basemap. OpenStreetMap is an explicit per-position external link that sends only that selected location to the provider.
## Satellite layer and external map

Satellite is an optional in-app layer using bundled JPEG snapshots of NASA Earth Observatory Blue Marble (August 2004, shaded relief and bathymetry). It is historical imagery, not vessel tracking, a navigation chart, or a current weather or bathymetry product. The world image uses an EPSG:4326 bounding box of south -90, west -180, north 90, east 180 (1440 x 720). The inset uses south -24, west -45, north -21.4, east -40 (1280 x 666); each image is served by WaveLink and loaded only when Satellite is selected. Source: https://wvs.earthdata.nasa.gov/ (BlueMarble_ShadedRelief_Bathymetry), credit NASA Earth Observatory, https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/.

Layer changes do not move the map. The focus selector centers on a reported vessel. The optional Google Maps link opens an external satellite view using just the camera center/zoom, without an API key or embedded Google script. The existing per-position OpenStreetMap links are unchanged.
