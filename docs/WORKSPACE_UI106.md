## Read and compare the proposal

Open **Setup & builders → Import a document**, choose the file and destination, and read it. For checklist, maintenance and toolbox documents, open **Review source interpretation** to inspect passages that need comparison with the source. Each point shows the reason for review, its available location and an excerpt when one could be read. **Review** opens or focuses the relevant existing editor control; it does not change the draft or approve an import.

Locations distinguish original Excel rows, PDF pages and printed row labels from extracted table positions, ordered blocks and text lines. Original coordinates are shown only when available. A PDF text area is approximate; plain OCR text does not establish a precise page or rectangle.

The panel describes the original reading of the file. Editing wording does not recompute recognition or mark a point resolved. Switching a worksheet changes the points to that worksheet. Older kept drafts without this evidence continue to work; compare their complete extracted text or reread the source.

## Correct instructions, tools and answers

Use the existing editor to keep instructions as instructions, warnings as warnings and answerable steps as checks. Review printed Yes/No, Sim/Não and Pass/Fail choices, reading units and before/after stages. A historical tick or answer in the source is never a new completed answer. Unspecified Status or Result columns require a deliberate decision about the response format.

Tool tables under an explicit required-tools heading and clearly printed Portuguese labels are recognized in the proposal. A standalone stock table is not assumed to be required tools. Ambiguous prose, uncertain stage headings, unmapped rows and recognition limits remain available for review. The importer does not determine the correctness of a maintenance procedure or establish an equipment relationship from visual formatting.

## Keep source guidance in a toolbox talk

A toolbox definition stores discussion prompts, understanding questions, supervisor instructions and an acknowledgement declaration. Separate checklist tools, instruction blocks, answer formats and before/after controls are not native toolbox fields.

When source instruction blocks or tools are available, use **Add instructions and tools to discussion** to include their wording in editable discussion groups. Review the resulting prompts. This deliberate edit clears the checked proposal and requires checking it again. Native prompt limits still apply; source guidance is not silently shortened to make it fit. Instructions and tools outside the toolbox discussion are not saved as separate fields.

## Check and save the current draft

Check the edited draft, compare the summary against the source, then confirm and save. The saved definition is unpublished. No historical answers, attendance, signatures, stock verification or operational history are created from the source. Pending or uncertain saves retain their original retry operation; wait for its result before changing the proposal.

Inventory row selection and original-source conflict review retain the UI105 flow. Importing an existing inventory preserves its items, checks, tasks and custody. Source files remain unchanged; keep your copy, because this importer records the filename and digest rather than uploading original bytes to Original files.
