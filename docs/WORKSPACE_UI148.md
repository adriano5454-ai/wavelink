# Wavelink 1.34.48

## Responsive builder actions

The checklist, maintenance, toolbox, logbook and inventory builders now arrange their actions using the available card width. On smaller cards, the OpenAI action spans the row and the two other actions appear below. Very narrow cards stack all three actions. At wider sizes the three actions share one row. The layout keeps the Portuguese labels readable when the navigation sidebar is open.

This update derives from Wavelink 1.34.47 at commit `39bf405d6ee7094b251274e0ce6fbcc338151837`. Release verification is recorded in `DELIVERY_CHECKS.json`.
